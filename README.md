# Virtual Banking System 

A **full-stack Virtual Banking System** built using **Spring Boot**, **MySQL**, **HTML**, and **CSS**.  
This application provides core banking functionalities with secure authentication and role-based dashboards for **customers** and **administrators**.

---

# Project Overview
The Virtual Banking System enables users to perform essential banking operations online through a responsive web interface. 
It supports secure account management, transaction tracking, and profile updates while ensuring reliable data persistence.

---

## Features

#Authentication & User Management
- User **Signup** and **Login**
- Secure authentication handling
- Profile update functionality (Name, Email, Password)

# Customer Dashboard
- View account details
- Deposit money
- Withdraw money
- Transfer funds to other users
- View passbook and transaction history

#Admin Dashboard
- Separate admin access
- View and manage customer accounts
- Monitor all transactions

#Data Persistence
- MySQL database integration
- Reliable transaction storage and retrieval

# Frontend
- Responsive UI built using **HTML** and **CSS**
- Seamless integration with Spring Boot backend
